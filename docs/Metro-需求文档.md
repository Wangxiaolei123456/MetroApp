# Metro 产品需求文档

## 1. 产品概述

### 1.1 定位

Metro 是一款「地铁出行 + 乘车打卡积分 + Uptick 链上钱包发奖」的移动应用。用户可在真实地铁线网地图上规划路线、围栏打卡乘车、获取积分，并在行程结束后由发奖账户向用户 **EVM 钱包直发原生 UPTICK**。

### 1.2 目标用户

- 地铁出行用户
- 需要体验「出行即挖矿 / 乘车发 Token」的早期 Web3 用户

### 1.3 技术栈

| 类别   | 选型                                                 |
| ------ | ---------------------------------------------------- |
| 客户端 | React Native 0.74.5、React 18、TypeScript 5.4        |
| 导航   | React Navigation（Bottom Tabs + Native Stack）       |
| 状态   | Zustand                                              |
| 地图   | react-native-maps（Google）                          |
| 定位   | react-native-geolocation-service                     |
| 存储   | AsyncStorage + EncryptedStorage                      |
| 链     | ethers v6（EVM）、@cosmjs（Cosmos 签名/查询）、bip39 |

### 1.4 信息架构

```
底部 Tab
├── 地图（Stack）
│   ├── 地图主页
│   ├── 路线规划
│   └── 车站线路浏览
├── 行程（乘车打卡）
├── 积分
├── 钱包
└── 我的（Stack）
    ├── 个人中心
    ├── 设置
    ├── 空投
    ├── 任务
    ├── 周边活动
    ├── 排行榜
    └── 帮助与反馈
```

### 2.3 乘车打卡（模块 B）

| 编号 | 需求                                    | 优先级 |
| ---- | --------------------------------------- | ------ |
| B1   | 手动开始行程；GPS 驱动进站/出站围栏计数 | P0     |
| B2   | 实时展示途经站数与站点列表              | P0     |
| B3   | 结束行程：结算站数、距离、时长          | P0     |
| B4   | 防作弊：速度 / 站间间隔 / 轨迹断点      | P0     |
| B5   | 仅「正常完成」的行程计入积分与发奖      | P0     |
| B6   | 行程历史本地持久化                      | P0     |
| B7   | 结束时向用户 EVM 钱包直发 UPTICK        | P0     |

**防作弊阈值（`APP_CONFIG.antiCheat`）**

| 参数                   | 当前值  | 说明                             |
| ---------------------- | ------- | -------------------------------- |
| `enabled`              | `false` | `false` 时不标记异常、不影响结算 |
| `maxPlausibleSpeed`    | 40 m/s  | 瞬时速度上限                     |
| `minStationIntervalMs` | 20_000  | 两站最小间隔                     |
| `maxTrackGapMs`        | 120_000 | 轨迹最大断点                     |

**结算流程（完成态）**

1. 生成积分流水（含部分锁定）
2. 累加用户 rides / stops
3. 按站数 × `rideTokenPerStop` 向 EVM 地址转原生 UPTICK
4. 写入本地行程历史（按 id 去重，避免重复结束）

### 2.4 积分体系（模块 C）

| 编号 | 需求                                                 | 优先级 |
| ---- | ---------------------------------------------------- | ------ |

### 2.5 钱包与链上发奖（模块 D）

| 编号 | 需求                                                                   | 优先级 |
| ---- | ---------------------------------------------------------------------- | ------ |
| D1   | 创建 / 导入 BIP39 助记词钱包                                           | P0     |
| D2   | 派生 Cosmos（uptick…）+ EVM（0x…）双地址（HD 路径 `m/44'/60'/0'/0/0`） | P0     |
| D3   | 助记词系统级加密存储（EncryptedStorage；失败可回退，仅开发）           | P0     |
| D4   | 查询 EVM 原生 UPTICK 余额（真实 RPC）                                  | P0     |
| D5   | 测试网 / 主网切换                                                      | P1     |
| D6   | 乘车奖励直发用户 EVM 钱包（不本地记账；ethers + treasury 私钥）        | P0     |
| D7   | 展示最近发奖结果（成功哈希 / 失败原因）                                | P1     |
| D8   | NFT / 链上交易历史                                                     | P2     |

**链配置**

| 环境   | Cosmos Chain ID | EVM Chain ID | EVM RPC                                   |
| ------ | --------------- | ------------ | ----------------------------------------- |
| 测试网 | `origin_1170-3` | 1170         | `https://json-rpc.origin.uptick.network/` |
| 主网   | `uptick_117-1`  | 117          | `https://json-rpc.uptick.network/`        |

**发奖规则**

- 每途经 1 站：`0.01 UPTICK`
- 开关：`rewardOnChain = true`
- 发奖账户：`rewardTreasuryKey`（配置内 hex 私钥或助记词；需持有 UPTICK 与 gas）
- **不经过本地 Token 账本**；余额以链上 `eth_getBalance` 为准

**浏览器核对（测试网）**

- 浏览器：https://evm-explorer.origin.uptick.network
- 注意：测试网 Blockscout 可能索引异常显示 0；以 RPC / App 为准更可靠

## 3. 非功能需求

| 类别     | 要求                     | 现状                                                 |
| -------- | ------------------------ | ---------------------------------------------------- |
| 离线     | 地铁数据、本地路由可离线 | ✅ 地铁 JSON 内置；Google 失败可降级                 |
| 安全     | 私钥不出设备             | ✅ 加密存储为主；treasury 密钥在配置文件（演示风险） |
| 性能     | 地图与列表可接受帧率     | 依赖设备；无专项压测                                 |
| 可访问性 | 系统减少动态效果         | ✅                                                   |
| 国际化   | zh / en                  | ✅                                                   |
| 隐私     | 定位可本地关闭开关       | ✅ 开关存在，需业务侧继续遵守                        |

## 7. 未完成 / 演示项（明确范围外或半成品）

以下内容**当前代码为演示或未接线**，正式产品需单独排期：

1. 空投真实链上领取与扣积分
2. 任务随行程自动推进与持久化；任务 Token 奖励
3. 活动 Token 实际上链；按城市过滤活动
4. 排行榜服务端数据
5. 真实短信 / OAuth 登录与邀请裂变发奖
6. NFT / 完整链上交易历史查询
7. 系统推送通知
8. 防作弊上线前需重新打开 `antiCheat.enabled` 并在真机校准阈值
9. 配置中的 Google API Key、发奖私钥不应提交生产仓库（需环境变量 / 密钥管理）
